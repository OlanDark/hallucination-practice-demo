# Демонстрационный проект: многоагентная проверка фактов

Python-прототип для обнаружения и исправления фактических ошибок в ответах языковой модели. Веб-интерфейс реализован на Streamlit. Источники для проверки: статьи Википедии. Вызовы языковой модели выполняются через Groq (OpenAI-совместимый API).

## Архитектура

1. **Generator** (`agents.py`) генерирует ответ на вопрос в режиме «Задать вопрос».
2. **Extractor** (`agents.py`) выделяет проверяемые факты из готового ответа и создаёт поисковые запросы.
3. **Wikipedia Search** (`wiki_search.py`) находит статьи и отбирает релевантные фрагменты с помощью BM25. Это обычный программный модуль, не LLM-агент.
4. **Verifier** (`agents.py`) присваивает каждому факту статус `SUPPORTED`, `REFUTED` или `NOT_ENOUGH_INFO` по найденным фрагментам.
5. **Editor** (`agents.py`) формирует исправленный ответ на основании результатов проверки.
6. **Orchestrator** (`pipeline.py`) управляет всеми этапами и собирает результаты.

`app.py` показывает интерфейс. `llm.py` выполняет обращения к Groq и собирает статистику. `config.py` хранит параметры. `experiment.py` — отдельный эксперимент для оценки на HaluEval QA с сравнением baseline и системы.

## Режимы приложения

- **Задать вопрос:** `HallucinationPipeline.run(question)` — ответ формирует Generator, затем происходит проверка.
- **Проверить свой текст:** `HallucinationPipeline.check(answer, question)` — проверка введённого пользователем текста без Generator.

## Запуск на своём компьютере

Требуется установленный Python. В папке проекта:

```bash
python -m venv venv
```

Windows, CMD:

```cmd
venv\Scripts\activate
pip install -r requirements.txt
```

Создайте локальный файл `.env` (не загружать в GitHub):

```text
GROQ_API_KEY=ваш_ключ_Groq
```

Запуск приложения:

```bash
python -m streamlit run app.py
```

Приложение откроется на `http://localhost:8501`.

## Публикация в Streamlit Community Cloud

Разместите эти файлы в **корне публичного GitHub-репозитория**. При создании приложения выберите этот репозиторий, ветку `main` и `app.py`. В Streamlit Cloud → Advanced settings → Secrets задайте **только там**:

```toml
GROQ_API_KEY = "ваш_секретный_ключ"
```

Настройка `GROQ_API_KEY` на верхнем уровне Streamlit Secrets доступна через переменные окружения Python, поэтому текущий `config.py` прочитает её без дополнительных изменений.

## Проверки и эксперимент

```bash
python -m unittest test_experiment test_agents_upgrade test_search_upgrade -v
python experiment.py --prepare
python experiment.py --run --pairs 1 --method both --split dev
```

Первый запуск тестов не использует Groq; `--prepare` скачивает HaluEval, но не вызывает LLM; `--run` обращается к Groq и расходует токены. Реальные результаты не гарантируют правильность каждого вердикта — это исследовательский прототип.

## Безопасность и ограничения

- **Никогда** не публикуйте `.env`, `.streamlit/secrets.toml`, ключи, личные данные и содержимое `cache/`.
- Публичное приложение использует квоту Groq владельца: другие посетители могут расходовать её.
- Система зависит от внешних Groq и Википедии. Ограничения запросов или временные ошибки могут влиять на работу.
- `NOT_ENOUGH_INFO` означает, что не было достаточных доказательств; текущая логика итоговой классификации имеет известные ограничения.

Инструкция пошаговой публикации находится в `ПУБЛИКАЦИЯ_ПО_ШАГАМ.md`.
